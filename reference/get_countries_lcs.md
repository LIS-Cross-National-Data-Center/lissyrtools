# Print all the country code in LCS

Print all the country code in LCS

## Usage

``` r
get_countries_lcs()
```

## Value

A data frame.

## Examples

``` r
get_countries_lcs()
#>        Belgium        Finland         France         Israel          Italy 
#>           "be"           "fi"           "fr"           "il"           "it" 
#>           Laos     Luxembourg           Mali         Mexico      Palestine 
#>           "la"           "lu"           "ml"           "mx"           "ps" 
#>    Philippines         Poland   South Africa          Spain    Switzerland 
#>           "ph"           "pl"           "za"           "es"           "ch" 
#> United Kingdom 
#>           "uk" 
```
