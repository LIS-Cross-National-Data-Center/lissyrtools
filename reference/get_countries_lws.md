# Print all the country code in LWS

Print all the country code in LWS

## Usage

``` r
get_countries_lws()
```

## Value

A data frame.

## Examples

``` r
get_countries_lws()
#>      Australia        Austria         Canada          Chile        Czechia

#>         Greece          India        Ireland          Italy          Japan 
#>           "gr"           "in"           "ie"           "it"           "jp" 
#>     Luxembourg         Mexico         Norway       Slovakia       Slovenia 
#>           "lu"           "mx"           "no"           "sk"           "si"
```
